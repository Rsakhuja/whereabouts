What models say they look at

With every guess, each model lists the 3–5 visual features it says led to its answer. We sort those features into types and add them up across all – photos. That shows what each model leans on, and which kinds of features go with correct answers.

How often each model cites each type of feature

Share of a model's answered rounds where at least one listed feature falls in that type. A feature can count towards more than one type.

Do those features pay off?

City accuracy on the rounds where a model cited that type of feature, compared with its accuracy over all rounds. Types cited fewer than 3 times aren't scored.

Read these with care

These are features models claim to use, not proof of what drove the answer. A model can name a feature after the fact, or describe something that isn't in the photo at all. In earlier runs, models confidently misread street signs and misidentified landmarks. Checking whether claimed features are actually in the photo is planned.

Feature types come from keyword rules (for example, "Cyrillic" or "script" counts as script and language). The rules are simple and transparent, but they will miss some phrasings. A pattern only becomes interesting when it shows up across many rounds.

Correlation, not cause. If citing landmarks goes with higher accuracy, that may be because photos with landmarks are easier, not because the landmark reasoning is better.
